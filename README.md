# 아리수 퀘스트

아리수 수질검사 방문지를 날짜별로 관리하는 모바일 웹앱입니다.

- 방문 목록 사진 → 기기 안에서 글자 인식(Tesseract.js, 무료) → 확인 후 목록 추가
- 수도사업소별 동선 정렬, 구간별 자동차·도보·대중교통 추정 시간과 카카오맵 길찾기 링크
- 좌표·자치구·행정동은 OpenStreetMap(Nominatim)으로 추정 (추정값 표시)
- 수질 기준(환경부 먹는물 수질기준) 표시와 측정값 판정
- 아이디·비밀번호 로그인(Supabase Auth), 보기 전용 공유 링크
- 다크/라이트, 글씨 크기 조절, 게임풍 연출

## 구성
- `index.html`, `app.js`: 정적 앱 (GitHub Pages)
- `supabase/migrations/`: DB 스키마와 보안 규칙(RLS)
- `config.js`: 배포 때 저장소 변수 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`로 생성 (커밋하지 않음)

## Supabase 무료 플랜에 맞춘 설정
- 사진은 서버에 올리지 않음 (Storage 0)
- 하루 목록 1건 200KB 이하, 하루 80곳, 사용자당 550일까지
- DB 500MB·가입자 5만 명의 80%를 넘으면 앱이 경고
- 실시간(Realtime) 미사용, 필요한 날짜만 불러와 전송량 절약
- 무료 프로젝트는 7일간 사용이 없으면 일시정지될 수 있음
